# Local App Usage

The current product path is the local `codex-to-im` app and web workbench.

Open the workbench with:

```bash
codex-to-im open
```

Fallback:

```bash
node dist/cli.mjs open
```

If the user asks to configure credentials, start or stop the bridge, inspect logs, or diagnose problems, use the local app instead of any Codex skill-based workflow.
